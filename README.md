# Privacy Policy for hamyar_cafenet Extension

**Last Updated:** August 3, 2026

## Overview
**NetCafé Pro** ("we", "our", or "extension") is a productivity dashboard and utility extension designed for Internet Cafes (NetCafé) and service centers. We respect your privacy and are fully committed to protecting user data.

---

## 1. Single Purpose Declaration
The primary purpose of **NetCafé Pro** is to provide Internet Cafe managers and operators with a consolidated management dashboard, including quick access to Iranian government e-services, automated tariff calculation, local task management, and smart utility tools directly inside the browser interface.

---

## 2. Data Collection & Usage

### 2.1 Locally Stored Data (Client-Side Storage)
* **Bookmarks, Notes & Tasks:** Created bookmarks, quick notes, to-do lists, and customer job logs are stored locally in the user's browser using `chrome.storage.local` and `localStorage`.
* **Application Preferences:** User settings (theme preference, layout choices, custom quick-access links) are kept entirely on the local device.
* **No Automatic Personal Data Collection:** The extension does **not** collect, scrape, or store personally identifiable information (PII), biometric data, health data, financial account credentials, browsing history, or keystrokes.

### 2.2 Optional Cloud Synchronization
* **Firestore / Google Drive Backup (Optional):** If the user explicitly opts into cloud backup or synchronization, backup packages containing user-created settings and notes are stored securely under the user's authenticated Google Firebase / Google Drive account.
* **Data Control:** Users can export, restore, or clear their local and cloud backups at any time through the extension's Settings panel.

---

## 3. Third-Party Services
* **Government & Utility Websites:** The extension provides direct navigation bookmarks to public Iranian e-service portals (e.g., Epolice, Sanjesh, Post, SabteAhval). The extension does not intercept credentials or form data submitted on those external websites.
* **API Requests:** AI assistance features use secure API proxies (`/api/*`). No sensitive user data is transmitted to third parties without user interaction.

---

## 4. Data Sharing & Disclosure
* **No Sale of Data:** We do **NOT** sell, trade, rent, or transfer user data to third parties under any circumstances.
* **No Tracking/Advertising:** The extension contains no tracking scripts, advertising SDKs, or analytics trackers aimed at user profiling.
